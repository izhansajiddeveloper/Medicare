# MediStock Pro - Medical Management Dashboard

MediStock Pro is a modern, web-based inventory management and analytics dashboard designed specifically for pharmacies and medical stores. It provides real-time insights into stock levels, alerts for low inventory and expiring medicines, and powerful visual analytics to help store owners make informed decisions.

## ✨ Features

- **Live Store Analytics:** Real-time overview of total medicines, in-stock items, low-stock reorders, out-of-stock items, total inventory value, and estimated reorder costs.
- **Visual Data Charts:** Interactive charts built with Chart.js to visualize stock distribution, category breakdowns, monthly growth trends, and overall stock health.
- **Custom Monthly Growth Graph:** Specially designed blue line graph with a growth arrow and faint background bars to indicate business growth trends.
- **Inventory Alerts:** Automatically flags critical low stock levels and medicines expiring within the next 30 days for immediate action.
- **Quick Operational Shortcuts:** A streamlined, compact UI (2-column layout) for quick access to common tasks like adding medicines, managing stock, viewing reports, and accessing settings.
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices using Tailwind CSS.
- **Secure Access:** Includes a login validation system to protect sensitive store data.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling Framework:** Tailwind CSS (via CDN)
- **Icons:** Font Awesome 6
- **Charts:** Chart.js 4
- **Typography:** Google Fonts (Inter)
- **Data Storage:** Browser LocalStorage (for demo/simulation purposes)
